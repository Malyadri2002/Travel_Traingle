Travel Triangle – Data-Driven Holiday Package Platform
	
  Analyzed user behavior, booking trends, and travel preferences to optimize holiday package offerings.
	Utilized data analytics to identify high-conversion tour types (e.g., honeymoon, adventure) and peak booking seasons.
	Developed interactive dashboards and reports to track key metrics such as destination popularity, average booking value, and agent performance.
	Implemented data filters for destination, duration, budget, and tour type to enhance user segmentation and targeting.
